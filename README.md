# 🏡 California Housing Price Prediction

Проект по машинному обучению, решающий задачу предсказания стоимости жилья в Калифорнии на основе социально-экономических и географических признаков. Создан для портфолио по направлению Artificial Intelligence.

---

## 📊 1. Описание задачи и датасет
* **Источник данных:** Встроенный датасет `fetch_california_housing` из библиотеки `scikit-learn` (база данных на основе переписи населения США 1990 года).
* **Целевая переменная (`MedHouseVal`):** Медианная стоимость домов в регионе (в сотнях тысяч долларов).
* **Признаки (Features):** 
  * `MedInc` — медианный доход домохозяйств.
  * `HouseAge` — средний возраст домов.
  * `AveRooms` — среднее количество комнат на одно домохозяйство.
  * `AveOccup` — среднее количество жильцов.
  * Географические координаты (`Latitude`, `Longitude`) и др.

---

## 🔍 2. Разведочный анализ данных (EDA) и Инсайты
В ходе анализа матрицы корреляции (Pearson Correlation) было выявлено:
* **Главный фактор стоимости:** Признак `MedInc` (средний доход) имеет самую сильную положительную корреляцию с ценой жилья ($r \approx 0.69$). Чем выше доход в районе, тем дороже недвижимость.
* Данные были очищены, а признаки масштабированы с помощью `StandardScaler` для корректной работы линейных моделей.

---

## ⚙️ 3. Сравнение моделей и результаты
Мы обучили две модели для решения задачи регрессии и сравнили их качество на тестовой выборке (20% данных):

| Модель | Коэффициент детерминации ($R^2 Score$) 📈 | Среднеквадратичная ошибка ($RMSE$) 📉 |
| :--- | :--- | :--- |
| **Linear Regression** | ~0.575 | ~0.745 |
| **Random Forest Regressor** | **~0.805** | **~0.506** |

> **Вывод:** Ансамбль деревьев решений (*Random Forest*) справился с задачей значительно лучше линейной регрессии, объясняя более 80% дисперсии данных.
